Hi.  You have a beta version of Edifice.  Here are some tips to get you started.

To edit your controls, open "control.ini" and assign a key to the different actions in the game.  If you want your mouse action reversed (pulling back makes view go up instead of down), then make mousereverse=1

The change your server and player name, open "net.ini" and edit the default names.

We don't suggest messing with object, skies, or sv.ini.  Mess with land.ini if you want the landscape to turn out differently, but make sure to backup the original first in case you totally screw up the way the ground looks!

ignore plmodel.exe.  it's what we're going to use to make player animations.

structure.exe is a tool for making buildings.  pageup and pagedown move between floor levels.  putting an "x" in a square designates a block on that level.  You start on the ground level.  Sorry for the vague instructions.  I don't know how to use it that well myself.

You can save the landscape you're in by selecting file-save.  You can also load landscapes. Save them all in the edifice root dir.

When you're in a game, try this.  go into the console (tilde key ~) and type "createdome" and hit enter.  A dome will appear.  You can pick it up with the use key (default is "q" or "v").  The team you're on (white, red, or blue) will hold the point.  The default team is white.  To change teams, type either "team0, team1, or team2" in the console.

To build, hit "b" and then select a directory and a building.  Follow on-screen instructions.

Jetpack is only temporary.  We don't want to copy tribes too much.

When you start out, you'll be holding a pisol.  To change weapons, hit either 1-6 on the keyboard or use your mousewheel if you have one.  You have unlimited ammo for each weapon right now, but have to reload the guns.  The default key for this is either "q" or "z"
